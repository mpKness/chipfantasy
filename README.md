## CHIPS FANTASY STATZ

### Commands

Get weekly summary of matchups, makes one csv that is the team matchups, and once csv that is a list of all players that were on teams in the league that week
`python main.py --week 17`

### env vars
command to load env vars into console
`source env.sh`

update `YAHOO_LEAGUE_KEY` to change which league the data is pulled from. To change the league being pulled from just change the value in env.sh and then rerun source command
